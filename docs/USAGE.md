# 使い方

最終更新: 2026-10-01 / 対象コミット: 368e752

## 起動

電源を入れると、パネルでは root で自動ログインし、sway が起動する。シリアルコンソールと ssh にはログインプロンプトが出る。

起動中に SELECT を押し続けると、sway を起動せずシェルに留まる。`start-sway` で後から起動できる。

## 画面

- 上端のバー: 電池残量、LED、押しているボタン
- 下半分: 画面キーボード
- 残り: 端末（foot）

## ボタンとスティック

| 操作 | 動作 |
|---|---|
| 左スティック | マウスカーソルを動かす |
| A | 左クリック |
| B | 右クリック |

ほかのボタンと右スティックは、ゲームパッドの入力として読める。

## キーボード

USB キーボードを OTG 端子につなぐと、次のキー操作が使える。

| キー | 動作 |
|---|---|
| `Alt` + `Enter` | 端末を開く |
| `Alt` + `q` | ウィンドウを閉じる |
| `Alt` + `k` | 画面キーボードの表示を切り替える |
| `Alt` + `i` | 状態表示を全画面で開く |
| `Alt` + `Shift` + `e` | sway を終了する |

## 電源を切る

```sh
poweroff
```
